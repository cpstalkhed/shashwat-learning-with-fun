# Shashwat Learning with Fun

GitHub Pages-ready educational mini-site.

## Files
- `index.html` — home page
- `Shashwat_Learning_with_Fun.html` — Marathi activities
- `Shashwat_Learning_with_Fun_English_Phonics.html` — English phonics

## Publish
1. Create a GitHub repository, preferably `shashwat-learning-with-fun`.
2. Upload all three HTML files.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then **Save**.
6. After deployment, open:
   `https://YOUR-USERNAME.github.io/shashwat-learning-with-fun/`
